# Emby 硬链接整理工具 v0.3.0 · 测试版

保留原文件名，在同一文件系统的另一目录生成短名称硬链接。只新增，不删除、不覆盖、不重命名原文件。硬链接失败会停止，不会自动复制整份视频。

## 第一次使用

1. 打开 EmbyLinkStudio.exe。
2. 在极空间开启 SSH，填写 NAS 局域网地址、SSH 端口、用户名及密码。不要填写 Emby 或 Double Commander 的登录信息。密码不会保存到配置文件。
3. 首次连接核对 SSH 主机指纹，再确认信任。保存后的主机密钥如果改变，软件会拒绝连接。
4. 原始目录和入口目录填写 NAS 实际路径，可在 WinSCP 中确认。不能填写 Windows 的 Y:\\ 路径，也不能填写容器路径 /data。
5. 点击“扫描并生成预览”。此步骤只读取 NAS，不创建文件或目录。
6. 检查原路径和短名对应关系，可导出 CSV。双击一行能查看完整路径。
7. 点击“确认后创建硬链接”。这是修改操作，软件会再次列出目标目录和数量，确认后才执行。建议首次只处理测试目录中的几个文件。

默认测试源：

`/sata11-EXAMPLE_USER/ASMR/fans/sample_author`

默认测试入口：

`/sata11-EXAMPLE_USER/ASMR/fans_hardlink/sample_author`

这两个路径根据此前 Emby 挂载配置填写，实际运行前请使用 WinSCP 确认。两个目录必须位于同一文件系统，不能相同或互相包含。

## 命名与批量处理

- 保留相对目录结构。目录名超过 80 个 UTF-8 字节才缩短，文件主名同样限制到 80 字节，扩展名单独保留。
- 长名称保留开头并附加由原名称计算的稳定编号。相同主名的 MP4、JPG、TXT、字幕等获得相同短主名。
- 原视频和封面主名本来不同的，不自动猜测配对。
- 自动跳过任意层级的 `.Trash`、`.Trash-*`、`#recycle`、`@Recycle`、`$RECYCLE.BIN`、`.recycle`、`.recyclebin` 及其全部内容；不清理已经存在的回收站或旧入口。正常隐藏文件不会一律跳过。
- 扫描处理其余全部普通文件，软链接及特殊文件跳过，不处理空目录。扫描有读取错误时不允许执行。
- 重新扫描跳过所有已经存在的普通目标文件，不覆盖；普通 SFTP 属性不包含设备号和文件编号，因此不会声称已有目标已经核验为硬链接。非普通目标标记冲突。
- 不同源文件映射到相同目标时停止扫描。不自动合并、替换或清理旧入口。
- 新增收藏后重新扫描，审核预览后只补充缺少的入口；第一版没有定时监控功能。
- 原目录或文件改名后，已有硬链接仍可用，但重新扫描可能生成新的相对入口。先检查预览，旧入口不会自动删除。
- 确保下载已经完成，再扫描创建；软件会检查预览后源文件大小和修改时间有无变化，但不能代替下载器完成状态检测。

## 使用 WinSCP 验证

1. 通过 SFTP 连接同一台 NAS，在入口目录查看新文件。
2. 原文件应仍保持原名称，新入口应为预览中的短名称，大小相同。
3. 文件大小相同本身不能证明是硬链接。本版通过 SFTP 硬链接专用扩展请求创建，服务返回成功后计为已创建；没有使用远程 stat 核对设备号或文件编号。
4. 若需独立核对，可在 WinSCP 的远程命令功能或 NAS 终端中对两个路径执行：

```sh
stat -c 'device=%d inode=%i links=%h size=%s name=%n' '原文件完整路径' '短入口完整路径'
```

5. 让 Emby 只扫描短入口目录，验证视频播放和封面。默认入口在当前 Emby 容器内预计对应 `/Z423_ASMR/emby_links_test`，以实际挂载为准。先添加独立测试库，不调整现有库。

## 需要知道的行为

- 创建硬链接不重复存储完整视频，但文件管理器可能对两个入口分别显示完整大小。
- 编辑任一入口的文件内容都会影响同一份数据。不要用软件改写原视频或封面内容。
- 删除原始文件的名称后，只要短入口还在，数据仍然占用空间。本工具第一版不提供自动清理，以免误删。
- 执行不是一个整体事务，失败会停止，已经创建的目录或链接保留。再次扫描可核对和继续。
- 若目录因 NAS 权限限制不能列出、SSH 账户不能创建硬链接，软件会报告错误，不会自动更改 NAS 权限。
- 当前只支持 SSH 密码登录，不支持交互式验证码或仅密钥登录。

连接设置、主机密钥及已创建记录位于 Windows 的 `%LOCALAPPDATA%\EmbyLinkStudio`。密码不写入这些文件。

## 验证范围

已进行本地命名规则、配套文件同名、目录包含关系、软链接目录拦截及窗口启动测试。尚未使用用户 NAS 的 SSH/SFTP 做端到端批量验证。请先使用小型测试目录，不要直接处理整个收藏库。

## v0.3.0 协议说明

创建前检查服务是否声明支持 `hardlink@openssh.com` v1，不支持就停止，不创建目录和链接。无需切换到支持 shell 的端口。端口 2022 是否支持该扩展，需要实际服务声明确认。已有普通目标仅跳过，不能依据大小相同断言是硬链接。
