# v0.11.1 · 开源准备与工程整理版

本版围绕批量创建硬链接整理开源工程，不改变已有命名规则、任务格式或创建确认流程。项目采用 MIT 许可证，第三方组件保留各自许可。

## 下载哪个文件
- EmbyLinkStudio-v0.11.1.exe：Windows 桌面程序，直接运行；属于便携程序，无独立安装向导。
- EmbyLinkStudio-NAS-v0.11.1.zip：NAS 首次部署完整包。
- EmbyLinkStudio-NAS-update-v0.11.1.zip：已有用户升级包。
- EmbyLinkStudio-source-v0.11.1.zip：对应发行源码。
- SHA256SUMS.txt：上述文件的 SHA-256 校验值；校验值不能代替签名或可信下载来源。

## 已完成
- 保留原名，创建名称兼容的硬链接入口；支持预览、核验、任务记录和停止恢复。
- 公共包不携带 .env、真实连接密钥或任务历史；首次部署由用户生成独立密钥。
- 增加 MIT 许可证、安全政策、贡献指南、发布清单、隐私规则检查和包内哈希。
- Windows/Linux、Python 3.12/3.13 四组自动检查已通过；Linux 专用保护与目录句柄回归已在 CI 执行。真实 NAS 环境仍需小范围验收。
- 修正跨平台测试样本与虚拟目录句柄模拟，未修改生产硬链接逻辑。
- 在线刮削暂缓，可继续使用已有成熟工具。

## 升级
Windows 和 NAS 两端使用同版本。NAS 更新 app 下全部 10 个 Python 文件，保留自己的 .env、state、自定义区域和 Compose 挂载；不要用公共示例覆盖实际配置。
升级后先只读扫描测试目录。创建硬链接属于修改操作，仍需在程序中确认。

## 运行边界
执行端当前要求 Linux x86-64；ARM 不受支持。默认 HTTP 仅用于可信局域网，不直接开放公网。
NFO 写入默认关闭。硬链接共享内容：改名互不影响，直接改写内容可能影响原件。
Windows 程序未做代码签名，不应把文件哈希或开源等同于平台签名认证。
