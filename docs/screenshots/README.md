# 软件界面展示

图片由真实的 EmbyLinkStudio Tk 界面截取，不是设计稿。所有媒体名称、目录、文件身份和核验结果都是合成样例；不连接真实 NAS，不读取操作者的用户设置，不修改媒体。

截图在 Linux/Xvfb 下渲染，因此系统控件外观与 Windows 略有差异。Windows 安装包仍使用原有系统界面，截图脚本不改变生产程序。

- preview.png：文件预览、命名和结果分类。
- verification.png：原件与入口的只读身份核验面板。

维护者确认需要更新图片时，可手动运行截图工作流，或修改 screenshot-request.json。截图辅助依赖 Pillow 与中文字体，不是软件运行依赖。
